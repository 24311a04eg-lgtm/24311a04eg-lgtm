## About Me

I am **Kota Karthik**, a cloud and DevOps enthusiast focused on turning application code into reliable, repeatable deployments. My projects explore the full path from infrastructure and containers to automation, Kubernetes operations, GitOps, and application delivery.

- Building cloud infrastructure with **AWS** and **Terraform**
- Deploying containerized applications with **Docker** and **Kubernetes**
- Automating delivery with **GitHub Actions**, CI/CD, and **Argo CD**
- Practicing Linux, scripting, Python services, and system design
- Learning by building projects that can be deployed, tested, and improved
- Open to collaborating on cloud, DevOps, platform engineering, and open-source work

> I like taking a working application and making the path from commit to production clearer, safer, and more automated.
